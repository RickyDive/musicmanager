# Attempt: remote controls from the Apple TV (for 2.2)

Status: **not in 2.1.** In Beta 3 the Now Playing banner (cover, artist, title) already works on the Apple TV with
"AirPlay as audio"; the Apple TV does not show play/pause, previous/next or the progress bar. This attempt was written but
not tested (not compiled); keep it for 2.2.

What it changes in `PlayerService.swift`:
1. Every `MPRemoteCommand` gets `isEnabled = true` so the receiver shows the controls.
2. Skip forward/backward commands with `preferredIntervals = [15]`.
3. `MPNowPlayingInfoPropertyDefaultPlaybackRate: 1.0` in the Now Playing info.
4. Every command received writes "In riproduzione: comando ricevuto — ..." in the detailed log, to see whether the Apple TV sends
   anything back (if nothing arrives, the AirPlay audio channel does not return commands and this route is closed).

Replacement for `setupRemoteCommands()`:

```swift
    /// Tasti multimediali, Centro di Controllo e comandi dell'Apple TV: play, pausa, avanti, indietro, posizione, salti di 15 s.
    /// Ogni comando va abilitato (`isEnabled`) perché il ricevitore AirPlay mostri i controlli; ogni comando arrivato si scrive
    /// nel log dettagliato, per vedere se l'Apple TV li invia davvero.
    private func setupRemoteCommands() {
        let center = MPRemoteCommandCenter.shared()
        func register(_ command: MPRemoteCommand, _ name: String, _ action: @escaping @MainActor (PlayerService) -> Void) {
            command.isEnabled = true
            command.addTarget { [weak self] _ in
                AppLog.debug("In riproduzione: comando ricevuto — \(name)")
                Task { @MainActor in if let self { action(self) } }
                return .success
            }
        }
        register(center.playCommand, "play") { player in
            if player.currentItem != nil, !player.isPlaying { player.togglePlayPause() }
        }
        register(center.pauseCommand, "pausa") { player in
            if player.currentItem != nil, player.isPlaying { player.togglePlayPause() }
        }
        register(center.togglePlayPauseCommand, "play/pausa") { $0.togglePlayPause() }
        register(center.nextTrackCommand, "avanti") { $0.onNext?() }
        register(center.previousTrackCommand, "indietro") { $0.onPrevious?() }
        center.skipForwardCommand.preferredIntervals = [15]
        register(center.skipForwardCommand, "salta avanti") { $0.seek(to: $0.currentTime + 15) }
        center.skipBackwardCommand.preferredIntervals = [15]
        register(center.skipBackwardCommand, "salta indietro") { $0.seek(to: max(0, $0.currentTime - 15)) }
        center.changePlaybackPositionCommand.isEnabled = true
        center.changePlaybackPositionCommand.addTarget { [weak self] event in
            guard let position = (event as? MPChangePlaybackPositionCommandEvent)?.positionTime else { return .commandFailed }
            AppLog.debug("In riproduzione: comando ricevuto — posizione \(position)")
            Task { @MainActor in self?.seek(to: position) }
            return .success
        }
    }
```
