# Scope / Ambito del progetto

**EN** — Music Manager moves *your own* music from the Music app on your Mac to a Garmin device you connect to that Mac. Data flows one way for music: Mac library → device. By design it does **not** read, list or copy the music library of other devices (for example an iPhone or iPad), and no such feature is planned. It does not remove copy protection (DRM) from any file. Please use it only with music you have the right to copy. Pull requests adding access to other devices' libraries will not be accepted.

**IT** — Music Manager sposta la *tua* musica dall'app Musica del Mac a un dispositivo Garmin collegato a quel Mac. Per la musica il flusso è a senso unico: libreria del Mac → dispositivo. Per scelta di progetto **non** legge, elenca né copia la libreria musicale di altri dispositivi (ad esempio un iPhone o un iPad) e non è prevista alcuna funzione di questo tipo. Non rimuove la protezione (DRM) da nessun file. Usalo solo con musica che hai il diritto di copiare. Non saranno accettate pull request che aggiungano l'accesso alle librerie di altri dispositivi.

**EN — Technical note.** The only files the app reads back from a device are small text files: the device's playlist files (M3U8, to show and import their track lists), a check copy of a playlist it has just written, and `GarminDevice.xml`. They go to a temporary folder that is deleted right away. Audio files are never copied from the device to the Mac; a playlist track that is not already in your Mac library is shown as "device only" and is not transferred.

**IT — Nota tecnica.** Gli unici file che l'app rilegge da un dispositivo sono piccoli file di testo: i file playlist (M3U8, per mostrarne e importarne l'elenco dei brani), una copia di controllo di una playlist appena scritta e `GarminDevice.xml`. Finiscono in una cartella temporanea che viene eliminata subito. I file audio non vengono mai copiati dal dispositivo al Mac; un brano di una playlist che non è già nella libreria del Mac risulta «solo sul dispositivo» e non viene trasferito.
